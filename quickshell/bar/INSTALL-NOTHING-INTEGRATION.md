# Edots Quickshell — Nothing integration

This is the full Quickshell project tree from the supplied integration archive, with the Nothing palette integration included.

## Install safely
1. Back up your existing Quickshell directory first.
2. Merge these files into the directory where your current `ShellNext.qml`, `theme/`, `surfaces/`, `services/`, and other Quickshell files live. Do not blindly replace unrelated personal files.
3. Install the companion `wallcolors.py` from the separate system-files archive to `~/.config/mango/scripts/wallcolors.py`.
4. Restart Quickshell and test Settings → Appearance/Design → Nothing / Material.

The archive has not been tested on your live desktop session. Keep a backup so you can revert if any QML import or local path differs.
